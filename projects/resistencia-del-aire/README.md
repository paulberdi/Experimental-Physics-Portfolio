# Resistencia del aire en un carro sobre riel de aire

Supporting material associated with the report [`Estudio experimental de la resistencia del aire en el movimiento de un carro sobre riel de aire`](../../papers/estudio-experimental-de-la-resistencia-del-aire-en-el-movimiento-de-un-carro-sobre-riel-de-aire.pdf).

## Contents

- `data/raw/` — original `.vcm` measurement files for runs with and without the vane.
- `data/processed/` — CSV summaries of accelerations and estimated air-force values.
- `analysis/ajuste-exp4-template.py` — Python analysis script uploaded with the experiment.

Duplicate CSV copies that were uploaded both at repository root and inside the previous `py/` folder were consolidated into a single `data/processed/` location.
