# Lanzamiento parabólico

Supporting material associated with the report [`Lanzamiento parabólico: contrastes entre teoría, medición experimental y modelado digital`](../../papers/lanzamiento-parabolico-contrastes-entre-teoria-medicion-experimental-y-modelado-digital.pdf).

## Contents

- `data/workbook.xlsx` — experimental workbook.
- `tracker/` — Tracker project files from the recorded trials.
- `figures/` — photographs and screenshots of the experimental and analysis setup.

The Tracker files are preserved with their original timestamp-based names so they can remain associated with the corresponding recordings.
