# Movimiento aleatorio en dos dimensiones

Supporting material associated with the report [`Movimiento aleatorio en dos dimensiones: análisis del desplazamiento cuadrático medio y clasificación del régimen dinámico`](../../papers/movimiento-aleatorio-en-dos-dimensiones-analisis-del-desplazamiento-cuadratico-medio-y-clasificacion-del-regimen-dinamico.pdf).

## Contents

- `data/workbook.xlsx` — experimental workbook uploaded with this project.
- `figures/montaje.jpg` — photograph of the experimental setup.
- `runs/28/`, `runs/31/`, `runs/35/`, `runs/50/` — material for the four sphere-count cases.

Each run directory preserves the corresponding spreadsheet, generated figures, analysis script and text output together. This keeps the original run-specific workflow intact while the project is being completed.
